  - sharp (Apache-2.0) bundles prebuilt libvips binaries, which are licensed
    under the GNU Lesser General Public License v3.0 or later

    gdk-pixbuf, librsvg, fribidi, libthai and others) that are licensed

The license of each package is included in its folder under node_modules.

4. Argos Translate (optional Translation Module, not bundled)
-------------------------------------------------------------
License: MIT License
  https://github.com/argosopentech/argos-translate

The optional offline Translation Module is not part of the installer. It can
be built with "npm run build-translation-module" and hosted separately. It
contains a Python 3.11 runtime (PSF License,
https://docs.python.org/3/license.html), the argostranslate library (MIT) and
